# オシダシ

押して、ぶつけて、落とす。デッキ構築 × マス目タクティクスのローグライト（1ファイルのブラウザゲーム）。

- 遊ぶ：https://20qolufiofleity14-lab.github.io/oshidashi/
- 内分泌アカデミーの「クイズ/遊ぶ → ミニゲーム」からも、アプリの中で開ける
- 記録（自己ベスト・実績・本気度・続き）は端末内（localStorage）に保存。アカデミーやミニ置き場と同じサイトなので共有される

## ファイル
- `index.html` … ゲーム本体。調整したい数値は先頭の `P` に【日本語名】でまとめてある
- `manifest.json` / `icon-*.png` / `apple-touch-icon.png` … ホーム画面に追加したとき用
